Contents of each directory in the repository:
configs/ - universal settings across scripts (i.e. simulation priors).
notebooks/ - up-to-date colab notebooks for executing research workflows.
scripts/ - python scripts immediately runnable by colab that execute a certain workflow, possibly combining functions across src scripts.
src/analysis - scripts for performing empirical inference and interpreting posterior data.
src/diagnostics - diagnostic and validation tests for the NPE.
src/data - processing empirical MaNGA spectra.
src/inference-model - building and training the model.
src/simulations - simulating synthetic training, validation, and test spectra.
src/utils - functions and data saving methods shared between scripts.
environment.yml - python environment specification.
requirements.txt - packages for colab to install to run scripts.

Data stored in each google drive folder:
Simulation data/ - where HDF5 files will be stored containing all simulated data in batches. This folder organizes the spectra by the stage of training they belong to, and then further into training, validation, and if applicable test spectra.
Posteriors/ - any posteriors returned from the model. This folder separates posteriors based on the dataset the posterior was inferred from and saves posteriors with true values when applicable (i.e. in simulated test data).
Notebooks/ - updated copies of google colab notebooks used to execute scripts.
Models/ - checkpoint for the trained model including all values needed to retain the models learning (i.e. model weights and biases, hyperparameters).
Model checkpoints/ - logs for model progress during training including learning rate, weighs and biases, validation loss curves, etc. The model will be checkpointed at the end of each runtime session where training was performed, and also periodically during training to monitor model progression and asses the need for early stopping.
Logs/ - any necessary documentation of work done by colab during individual runtime sessions (i.e. simulation progress logs)
Figures/ - additional figures for presentation generated by any scripts.
Empirical data/ - raw and processed MaNGA spectra and corresponding saved values stored separately in this folder.
Diagnostics/ - results and visual output from diagnostic tests.
